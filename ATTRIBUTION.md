# Attribution

This file records third-party assets, names, data notes, and licensing status for Municipal Carbon Assessor: Antalya Protocol.

## Runtime Dependencies

The project uses no npm packages, frameworks, game engines, databases, APIs, or paid services. It is built with HTML5, CSS3, and Vanilla JavaScript (ES6 modules) and runs as static files in a browser.

## Visual Assets

No external images, icon packs, illustration packs, or other visual assets are bundled in this repository at this time. The `assets/icons/` directory is reserved for project-owned SVG icons and symbols.

If a third-party visual asset is added later, record its source, author, and license here before release.

## Fonts

No font files are bundled. The design may reference `JetBrains Mono`, `Fira Code`, and `Inter` by name, with system font fallbacks. If any of these fonts are later bundled, their license and source must be added to this file.

## Audio

No audio files or samples are bundled. Planned sound effects use the browser Web Audio API and are synthesized at runtime by project code.

## Emission Factors and Case Data

Emission rates in `GAME_RULES.md` are fixed gameplay benchmark values for this game. They are described as municipal assessment rates and are not official COP31, United Nations, Antalya government, or scientific emission factors.

Citizen names, districts, notes, receipts, and cases are fictional game content. Any resemblance to real individuals or households is coincidental.

## Inspiration and Names

The game is mechanically inspired by *Papers, Please* by Lucas Pope. This project is not affiliated with, endorsed by, or derived from that game's code or assets.

References to COP31, the United Nations, Antalya, or related institutions are used descriptively for the game's setting. They do not imply endorsement, partnership, or official status.

## AI-Assisted Development

This project was developed for a game jam using AI coding agents, including OpenCode and Antigravity, as part of the project workflow. Development used a free static web stack and did not require proprietary services or licensed runtime assets.

## Licensing Status

No open-source license has been declared for this repository at this time. No `LICENSE` file is present. The project owner should add an explicit license before public redistribution or reuse.

Any future third-party code or asset must be compatible with the project's distribution terms and documented in this file.
